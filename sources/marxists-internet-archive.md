## Por que esta fonte foi adicionada

A primeira versão contemporânea deste repositório foi produzida a partir de uma edição em português.

A versão do Marxists Internet Archive foi adicionada posteriormente como **fonte cruzada de conferência**, porque:

1. identifica claramente a tradução inglesa de 1888, preparada por Samuel Moore em cooperação com Engels;
2. preserva o preâmbulo anterior à Parte I;
3. contém notas associadas à edição inglesa;
4. inclui vários prefácios históricos de Marx e Engels;
5. permite diferenciar o Manifesto principal de materiais complementares.

## Estrutura do PDF

O arquivo possui 68 páginas, mas o Manifesto principal ocupa aproximadamente as páginas 14–34.

As demais páginas incluem introdução editorial, prefácios, textos preparatórios, documentos políticos relacionados e notas.

Portanto, o total de páginas desse PDF **não deve ser usado como contagem de páginas do Manifesto em si**.

## Uso no projeto

Esta fonte não substitui a edição-base em português.

Ela funciona como uma segunda referência para:

- verificar se argumentos desapareceram durante a adaptação;
- conferir a estrutura;
- identificar notas históricas;
- distinguir conceitos de escolhas específicas de tradução;
- orientar uma futura v2 mais próxima de uma correspondência integral.
