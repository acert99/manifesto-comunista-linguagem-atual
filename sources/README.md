# Edição-base

Esta pasta identifica a edição em português utilizada como referência para a atualização de linguagem deste projeto.

O arquivo `manifesto-comunista-edicao-base.pdf` é a fonte de comparação. A versão em linguagem atual não deve ser tratada como substituta do texto-base: em passagens importantes ou controversas, a recomendação é comparar as duas versões.

A presença da fonte no mesmo repositório tem um objetivo simples: tornar o processo transparente e auditável.
