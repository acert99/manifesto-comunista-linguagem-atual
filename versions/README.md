# Histórico de versões

## v1 — condensada

Arquivo: [v1-condensada.md](./v1-condensada.md)

Primeira tentativa de atualizar o Manifesto para português contemporâneo. Preservou a estrutura e os conceitos principais, mas a auditoria posterior mostrou condensações e omissões relevantes.

Métricas reproduzíveis:

- 6.037 palavras;
- 42.042 caracteres;
- 279 blocos de texto;
- sem o preâmbulo do “espectro”.

## v2 — integral

Arquivo: [v2-integral.md](./v2-integral.md)

Versão reconstruída com a tradução inglesa de 1888 de Samuel Moore/Friedrich Engels como controle principal de cobertura e a edição portuguesa como referência cruzada de terminologia.

Métricas reproduzíveis:

- 10.544 palavras;
- 72.787 caracteres;
- 451 blocos de texto;
- preâmbulo + quatro partes;
- PDF gerado com 32 páginas.

A v2 também é publicada na raiz como [manifesto.md](../manifesto.md).

## Princípio de versionamento

Versões antigas não são apagadas. Mudanças relevantes de cobertura, metodologia ou interpretação editorial devem permanecer auditáveis no histórico do projeto.
